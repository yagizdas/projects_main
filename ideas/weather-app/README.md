# Atmos weather

Atmos is a responsive, key-free weather app powered by Open-Meteo. It includes city autocomplete, browser geolocation, current conditions, 24-hour and seven-day forecasts, and a Celsius/Fahrenheit switch. The interface adapts to the weather and time of day.

## Run locally

From the repository root, start any static file server:

```bash
python3 -m http.server 8000
```

Then visit <http://localhost:8000/ideas/weather-app/>. An internet connection is required to retrieve forecasts.
