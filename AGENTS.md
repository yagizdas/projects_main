# Incubator rules for coding agents

- Every project lives in its own folder: `ideas/<project-name>/`.
- Only touch the folder named in your task. Never edit other idea folders or root files unless the task says so.
- Each idea is self-contained: its own README, dependencies (e.g. requirements.txt, package.json) and its own AGENTS.md if present. Read that file first.
- Specs arrive as `ideas/<project-name>/TASK.md`. Implement it, then delete TASK.md in your final commit.
- Keep a short README in each idea folder with how to run it.
